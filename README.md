# Hyrox Asia Team Relay Men - PWA

This is a Progressive Web App (PWA) built to explore, filter, and calculate statistics for the **Hyrox Asia Team Relay Men** dataset. It can be hosted for free on **GitHub Pages** and installed on mobile devices or computers.

## Features
- **Instant Filtering**: Filter by Location (Bangkok, Jakarta, Singapore), Season, Age Group (U40, 40+), and search by athlete names or team countries.
- **Dynamic Analytics**: Automatically calculates **Fastest Time**, **Slowest Time**, and **Average Time** for whatever filtered subset your friends select.
- **PWA & Offline Ready**: Can be installed as a native app on iOS, Android, macOS, or Windows and works completely offline.

---

## How to Host on GitHub Pages (Step-by-Step)

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com) and create a new public repository (e.g., `hyrox-relay-pwa`).

2. **Upload Files**:
   - Upload all the files in this folder (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) directly into the repository root.

3. **Enable GitHub Pages**:
   - In your repository, go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.

4. **Access Your PWA**:
   - Within a minute, GitHub will give you a live URL (e.g., `https://yourusername.github.io/hyrox-relay-pwa/`). Share this link with your friends!
